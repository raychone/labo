# Module Documents

Module documents describe current behavior and planned boundaries. They do not replace code, migrations, or tests as proof of implementation.

Common structure:

- Status
- Purpose
- Roles and permissions
- Domain concepts
- Business rules
- Data model
- API
- UI
- Audit
- Security
- Edge cases
- Implemented tasks
- Planned tasks
- Deferred
- Open decisions
- Related documents
